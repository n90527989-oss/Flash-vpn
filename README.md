# سایت فروش VPN (Cloudflare Pages + D1)

## فایل‌ها (همه در ریشه، بدون پوشه)
- `index.html` `style.css` `app.js` — سایت، سبد خرید، ورود/ثبت‌نام، پنل کاربری
- `admin.html` `admin.js` — پنل مدیریت در `/admin`
- `_worker.js` — سرور (API، دیتابیس، امنیت). Cloudflare این فایل را خودکار اجرا می‌کند.
- `README.md` — همین راهنما (به‌صورت عمومی نمایش داده نمی‌شود)

## راه‌اندازی
1. همه‌ی فایل‌ها را در ریشه‌ی یک ریپوی GitHub آپلود کن.
2. Cloudflare ← Workers & Pages ← Create ← Pages ← Connect to Git ← ریپو را انتخاب کن.
   Framework = None، Build command خالی، Build output directory = `/`
3. بعد از اولین دیپلوی، در Settings ← **Bindings** یک **D1 database** با نام متغیر `DB` وصل کن.
   (دیتابیس را از Storage & Databases ← D1 بساز.)
4. در Settings ← Variables and Secrets به‌صورت **Secret**:
   - `ADMIN_PASSWORD` — رمز قوی مدیر (۱۲+ کاراکتر)
   - `SESSION_SECRET` — یک رشته‌ی تصادفی ۳۲+ کاراکتری
5. یک بار دیگر Deployments ← **Retry deployment** (یا یک commit کوچک) تا تنظیمات اعمال شود.
6. برو `/admin` ← وارد شو ← تب «تنظیمات»: شماره کارت، آدرس USDT و آیدی تلگرام را بزن.
7. تب «امنیت» ← **ورود دومرحله‌ای** را فعال کن.

جدول‌ها و سه پلن نمونه خودکار ساخته می‌شوند؛ نیازی به اجرای SQL نیست. پلن‌ها را از تب «پلن‌ها» ویرایش کن.

## جریان فروش
1. مشتری پلن را به سبد اضافه می‌کند ← ثبت‌نام/ورود ← **ثبت سفارش**.
2. مبلغ را کارت‌به‌کارت یا USDT واریز می‌کند و در پنل خودش **شماره پیگیری** را ثبت می‌کند.
3. سفارش در `/admin` ← «سفارش‌ها» ← «در انتظار بررسی» ظاهر می‌شود.
4. بعد از دیدن واریز، لینک اشتراک‌ها را از پنل VPN خودت (مثل Marzban) می‌سازی، هر خط یک لینک می‌چسبانی و **تأیید و تحویل** می‌زنی.
5. لینک فوراً در پنل کاربر نمایش داده می‌شود.

## اگر موبایل 2FA را گم کردی
متغیر `ADMIN_2FA_OFF` = `1` را موقتاً بگذار، با رمز وارد شو، 2FA را دوباره راه بینداز و متغیر را پاک کن.

## امنیت
CSP و هدرهای امنیتی، رمز کاربران با PBKDF2، قفل ۱۵ دقیقه‌ای بعد از ۵ رمز اشتباه مدیر، محدودیت نرخ ثبت‌نام/ورود/سفارش/تیکت،
مسدودسازی IP، حالت «در حال به‌روزرسانی»، بلاک مسیرهای اسکنر، ابطال نشست‌های مدیر و لاگ رویدادها.
